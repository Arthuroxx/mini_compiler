# mini_compiler

A compiler simulator built in Python 3.10+ for the Compilers course.

## Structure

- `src/mini_compiler/`: package containing the compiler modules.
- `tests/`: pytest tests.

## Requirements

- Python 3.10 or higher.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
```

## Tests

```bash
pytest
```
